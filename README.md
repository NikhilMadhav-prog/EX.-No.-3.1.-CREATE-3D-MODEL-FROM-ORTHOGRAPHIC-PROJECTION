# EX. No.3.1. CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION

## AIM

To design and draft the given orthographic engineering drawing with accurate dimensions
using Autodesk Fusion 360 and convert it into a three-dimensional solid model.

## REQUIREMENTS

→Autodesk Fusion 360 (Education License).
→Windows 10 or a compatible Windows operating system.
→Computer system capable of running 3D CAD modelling software.
→Stable internet connection for accessing Autodesk Fusion services.

## PROCEDURE

**1. Create and save a new design**

Open Autodesk Fusion, create a new design, and save it with a suitable project name.

<img width="1056" height="682" alt="New Part" src="https://github.com/user-attachments/assets/5a02ef48-0088-4eef-a1e8-3bf8a831d00a" />

<img width="1061" height="567" alt="Save" src="https://github.com/user-attachments/assets/23e8ab49-631a-4546-a093-57829a486444" />

**2. Start the main sketch**
 
Select Create Sketch and choose a suitable plane for the front profile of the bracket.

<img width="318" height="396" alt="Sketch Plane" src="https://github.com/user-attachments/assets/ae01d79f-0b5f-4ad4-988b-d10d939b7305" />

**3. Draw the main bracket profile**

Draw the bracket’s front outline, including the rounded end and rectangular body. Use the reference drawing to position the features.

<img width="540" height="691" alt="Create Sketch" src="https://github.com/user-attachments/assets/7c87842c-826e-45fd-b0a5-dd820c6bd664" />

<img width="697" height="561" alt="Lines" src="https://github.com/user-attachments/assets/fb6699df-a1f0-4de8-a71c-8fb06fa713ed" />

**4. Dimension the main profile**

Set the overall body height to 40 mm , 52 mm length and apply the 11 mm and 18 mm as shown in the drawing.

<img width="876" height="662" alt="3 1 Sketch-1" src="https://github.com/user-attachments/assets/28617679-03c8-4b56-80e8-4eec331192ac" />

**5. Extrude the main Body**

Finish the sketch and select the rectangular profile. Use the Extrude command to create the solid base plate with a thickness of 32 mm.

<img width="186" height="218" alt="Finish Sketch" src="https://github.com/user-attachments/assets/674a7afe-7b03-4386-a51b-b9445c3fd71d" />

<img width="466" height="607" alt="Extrude" src="https://github.com/user-attachments/assets/fb662196-f576-470e-8e09-e98083c61685" />

**6. Create the rounded-end hole**

Select the side face and start a sketch. Draw a concentric hole with a diameter of Ø16 mm and draw another circle of R16 mm.

<img width="536" height="542" alt="Circle" src="https://github.com/user-attachments/assets/426d28fd-1398-48cb-9e2f-080929d4b453" />

<img width="732" height="618" alt="3 1 Sketch-2" src="https://github.com/user-attachments/assets/20312bc5-5c96-4e09-ab87-dbb328218c3d" />

**7. Cut the rounded-end hole**

Use Extrude with the Cut operation to extend the hole and the extra curve outside the circle.

<img width="312" height="428" alt="image" src="https://github.com/user-attachments/assets/d20b4c1f-60c8-498d-bb60-442e676ab8f8" />

**8. Sketch the projecting pin**

Select the opposite end face of the bracket and draw a centred circle with a diameter of Ø18 mm.

<img width="501" height="546" alt="3 1 Sketch-3" src="https://github.com/user-attachments/assets/e110aa33-1459-41af-bd55-ec3ccd7cd3c6" />

**9. Extrude the pin**

Extrude the circle outward to create the cylindrical pin. Set its projection length to 32 mm, as shown in the drawing.

<img width="466" height="607" alt="Extrude" src="https://github.com/user-attachments/assets/5fd51185-9272-4a71-99d6-6a5b2aaeac0e" />

<img width="312" height="391" alt="Extrude Pop" src="https://github.com/user-attachments/assets/0f604d01-3299-4f46-ad46-aee7f0872ada" />

**10. Inspect and verify the completed model**

Rotate the model using the ViewCube and inspect it from different orientations. Check the important dimensions against the given engineering drawing.

<img width="845" height="702" alt="3 1 Extrude" src="https://github.com/user-attachments/assets/469fd482-bdc4-4c9c-999f-10153a8573c4" />

**11. Save the completed 3D model**

After verifying the geometry and dimensions, save the completed design in Autodesk Fusion 360. Ensure that all the modelling features are properly maintained in the design timeline for future modifications.

**12. Create a drawing file**

Choose Drawing > From Design, select a suitable sheet size, and place the front, top, and right views. Add an isometric view if needed to show the 3D shape clearly.

<img width="1056" height="682" alt="New Drawing" src="https://github.com/user-attachments/assets/2b796999-feff-4a66-aae6-10ead7cc5706" />

The Drawing was set to Manual for further processing.

<img width="493" height="541" alt="Drawing pop" src="https://github.com/user-attachments/assets/fcb5b264-5af0-430f-b021-6a6ad39a4536" />

**13. Add dimensions and save**

Add the dimensions shown in the reference: R16 mm, Ø16 mm, Ø18 mm, 32 mm, 40 mm, 52 mm, 36 mm, and the fork dimensions 18 mm and 11 mm. Arrange the annotations clearly, then save the drawing file.

<img width="250" height="557" alt="Drawing Dimensions" src="https://github.com/user-attachments/assets/e888d2f2-d7c9-4efb-aa05-aff788cc967e" />
